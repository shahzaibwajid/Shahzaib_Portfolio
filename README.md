# Shahzaib Wajid — Personal Portfolio

A responsive personal portfolio and online CV built with plain HTML, CSS, and JavaScript for the CodeAlpha Front-End Web Development internship task.

## Features

- Dark navy and electric-blue visual theme
- Responsive desktop and mobile layouts
- About, technical skills, projects, education, experience, and contact sections
- Mobile navigation menu
- Scroll reveal effects and active navigation
- GitHub, LinkedIn, and email links
- No framework or build step required

## Project structure

```text
shahzaib_portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── profile-placeholder.svg
```

## Run locally

Open `index.html` in a modern browser. For a more realistic local server preview, open this folder in VS Code and use the Live Server extension.

## Personalize before publishing

1. Replace `assets/profile-placeholder.svg` with your own photo. Save it as `profile.jpg` or `profile.png`, then update the image path and alt text in `index.html`.
2. Verify the project descriptions and add direct repository/demo URLs for Syed Farm House, Calculator, and academic projects.
3. Replace the illustrative project artwork with screenshots of your real projects.
4. Add a public-safe PDF resume only after checking whether it contains personal information you do not want online. The original CV contains a phone number; this starter site intentionally does not display it.
5. Confirm that the email and social profile URLs are the ones you want public.
6. Review the internship wording and update it after the internship period has ended.

## Publish with GitHub Pages

GitHub Pages hosts static HTML, CSS, and JavaScript from a GitHub repository.

1. Create a repository such as `shahzaib-portfolio` on GitHub.
2. Upload the contents of this folder; make sure `index.html` is at the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. Wait for the Pages deployment to finish, then open the URL shown in the Pages settings.

Project site URLs generally use this format: `https://USERNAME.github.io/REPOSITORY/`.

> GitHub Pages serves static websites; it will not run PHP or connect directly to a MySQL database. The portfolio itself is static, which makes it suitable for Pages.
